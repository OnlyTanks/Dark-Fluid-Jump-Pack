## Custom Jump Pack — Dark Fluid Vessel
### [**Showcase**](https://youtu.be/B26yMW2kFgg?si=CWV61nTJkmt1ePqb)

A HELLDIVERS 2 mod that replaces the normal **Jump Pack** with the real **Dark Fluid Vessel**.

The normal Jump Pack stratagem remains the one you select in your loadout, but when the Hellpod lands it spawns the Dark Fluid Vessel instead.

## Features

- Replaces the Jump Pack payload with the **real Dark Fluid Vessel**
- Uses the normal **Jump Pack stratagem**
- No extra Dark Fluid Vessel stratagems added to the HUD
- No purple question-mark placeholder
- Uses the Dark Fluid Vessel's real in-game entity/resources
- Critical-error logging only
- Designed for **HD2Arsenal + Bingus Shared Loader**

## Requirements

- **HELLDIVERS 2**
- [**HD2Arsenal**](https://www.nexusmods.com/helldivers2/mods/4664)
- [**Bingus Shared Loader v18 or newer**](https://github.com/CowboyBingus/BingusSharedLoader)

## Installation

1. Remove or disable any older **Custom Jump Pack** versions.
2. Install the mod ZIP through **HD2Arsenal**.
3. Make sure **Bingus Shared Loader v18+** is installed and enabled.
4. Purge / Deploy your mods if required by your HD2Arsenal setup.
5. Fully restart HELLDIVERS 2.

## Usage

Select the normal **Jump Pack** stratagem in your loadout.

When you call it in:

```text
Jump Pack Stratagem
        ↓
Hellpod lands
        ↓
Dark Fluid Vessel
```

The normal Jump Pack item is replaced by the Dark Fluid Vessel.

## Logging

The release build stays silent during normal operation.

A log is only written when a critical error occurs:

```text
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\CustomJumpPack.log
```

## Updating

HELLDIVERS 2 updates can change internal game data and may temporarily break the mod.

If that happens:

1. Disable the mod.
2. Check for an updated release.
3. If needed, attach `CustomJumpPack.log` to the bug report.
(**If the mod stops working after a HELLDIVERS 2 update, include this log when reporting the issue.**)
